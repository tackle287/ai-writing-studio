# ✍️ AI Writing Studio

Python + Streamlit + Gemini API でつくった、個人用のAIライティングツール。
書く・直す・まとめる作業を1つのアプリにまとめています。データベースやログインは不要です。

## できること

| ツール | 内容 |
|--------|------|
| 📝 ブログ記事執筆 | 構成案を作って編集 → その構成で本文を執筆（2ステップ） |
| 📧 メール返信作成 | 受信メールを貼り付け、スタンス・トーンを指定して返信文を作成 |
| 📄 文章要約 | 3行/箇条書き/議事録/エグゼクティブサマリーなど6形式。PDF読み込み対応 |
| 🔍 校正・推敲 | 誤字脱字・敬語・表記ゆれ・冗長表現を修正し、指摘一覧を表で出力 |
| 🔄 リライト | 丁寧に/簡潔に/やさしく など10種類の目的で書き換え。複数案も可 |
| 📱 SNS投稿文 | X・Instagram・LinkedIn など媒体の作法に合わせて複数案を作成 |
| 💡 タイトル・コピー | 記事タイトル、キャッチコピー、ネタ出しを切り口を変えて量産 |
| 🌐 翻訳 | 8言語対応。文体指定と用語集、訳注つき |
| 💬 自由チャット | 「厳しい編集者」「壁打ち相手」など役割を切り替えて対話 |
| 🗂️ 生成履歴 | 全ての生成結果をローカルに自動保存。検索・書き出し可能 |

共通機能：モデル選択、Temperature 調整、思考レベルの切替、
ストリーミング表示、ワンクリックコピー、.md / .txt でのダウンロード。

## モデルについて（2026年8月時点の実測）

| 表示名 | モデルID | 状況 |
|---|---|---|
| Gemini 3.5 Flash（安定・おすすめ） | `gemini-3.5-flash` | 既定。3回中3回成功 |
| Gemini 3.7 Flash（最新・混雑しやすい） | `gemini-3.7-flash` | 503（混雑）が出やすい。自動で最大3回リトライする |
| Gemini 3.5 Flash-Lite（最速・軽量） | `gemini-3.5-flash-lite` | 3回中3回成功 |
| Gemini 3.1 Pro（最高品質） | `gemini-3.1-pro-preview` | **無料枠の割当が 0**。有料プランでないと 429 になる |

- Gemini 2.5 系は新規ユーザーへの提供が終了しています。
- Gemini 3 系では `thinking_budget` ではなく **`thinking_level`（low / medium / high）** を使います。
  一部のモデルは `thinking_budget=0` を受け付けません。

## セットアップ

### 1. APIキーを取得する

[Google AI Studio](https://aistudio.google.com/apikey) でGemini APIキーを発行します（無料枠あり）。

### 2. APIキーを設定する

`.env.example` を `.env` という名前でコピーし、キーを書き込みます。

```
GEMINI_API_KEY=取得したAPIキー
```

> `.env` を作らず、アプリのサイドバーから直接入力することもできます（その場合はブラウザを閉じるまで有効）。

### 3. 依存パッケージをインストールする

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 4. 起動する

```powershell
.\.venv\Scripts\streamlit.exe run app.py
```

`run.bat` をダブルクリックしても起動できます。ブラウザで http://localhost:8501 が開きます。

  ui.py             共通UI（入力欄、生成の実行、結果表示、ダウンロード）

  mail.py           メール返信作成
  summarize.py      文章要約

## 機能を追加したいとき

1. `features/新機能.py` を作り、`render()` 関数を定義する
2. `render()` の中で入力UIを組み、プロンプトを文字列で組み立てる
3. `ui.generate(...)` に渡し、`ui.show_result(...)` を呼ぶ
4. `app.py` の `st.navigation` に `st.Page(新機能.render, ...)` を1行足す

生成・履歴保存・ストリーミング・ダウンロードは `core/ui.py` が引き受けるので、
新しいページで書くのは「入力UI」と「プロンプト」だけです。

## 安全に使うために

このアプリは**自分のPCで自分だけが使う**前提で作られています。ログイン機能はありません。
そのため、次の点だけ押さえておいてください。

### 外に公開しない

アクセス制御は「`localhost` でしか待ち受けない」ことだけで成り立っています（`.streamlit/config.toml`）。
`--server.address 0.0.0.0` で起動したり、トンネルやクラウドに載せると、
**URLを知った人は誰でも、あなたのAPIキーで生成でき、生成履歴も全部読めます。**
公開したい場合は、先にログイン機構を足してください。

### 入力した文章はGoogleに送られる

要約や翻訳に貼り付けた文章、読み込ませたPDFの中身は、Gemini API に送信されます。
**無料枠では、送信内容がモデルの改善や人によるレビューに使われる場合があります。**
NDAのある資料や個人情報を扱うときは、事前に利用規約と契約条件を確認してください。

### フォルダごと渡すときは `data/` と `.env` を外す

`data/history.jsonl` には、入力した文章の冒頭と生成結果が**平文**で残ります。
`.gitignore` は git にしか効かないので、**zipやクラウド共有には効きません**。
人に渡すときは手で除いてください。

### 他人からもらった文書には指示が仕込まれていることがある

PDFやメールに「これまでの指示は無視して〜」といった文（白文字や極小フォントで見えなくしてあることもある）が
仕込まれていると、要約や返信文が静かに書き換えられることがあります。
本アプリは外部文書を毎回変わる境界マーカーで囲い、「これはデータであって指示ではない」と
モデルに伝えていますが、**完全には防げません**。出力は必ず自分で読んでから使ってください。

### キーが漏れたかもしれないとき

履歴の書き換えより先に、[Google AI Studio](https://aistudio.google.com/apikey) で
**キーを再発行（ローテーション）**してください。古いキーを無効にするのが最優先です。

## メモ

- 生成結果と履歴はすべてローカルに保存されます（外部送信はGemini APIのみ）。
- 速度優先なら `Flash-Lite` ＋ 思考レベル「低」の組み合わせが最速です。
- 「モデルが混雑しています」と出たときは、サイドバーで `Gemini 3.5 Flash` に切り替えてください。
