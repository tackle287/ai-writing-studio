# バージョンを固定している理由:
# >= 指定だと、入れ直したときに何が入るか分からない。万一どれかのパッケージが
# 乗っ取られた版を公開しても、そのまま引き込んでしまう。引いたコードは
# あなたの権限で動くので、.env も data/ も読める。固定してあれば巻き込まれない。
#
# 更新するときは意図的に:
#   .\.venv\Scripts\python.exe -m pip install -U streamlit google-genai python-dotenv pypdf
#   .\.venv\Scripts\python.exe -m pip freeze > requirements.lock
# で新しい版を確認してから、この数字を書き換える。

streamlit==1.62.0
google-genai==2.19.0
python-dotenv==1.2.3
pypdf==6.16.1
